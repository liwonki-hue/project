# 해외 플랜트 현장 실무 교재

해외 플랜트 건설 현장에서 일하는 직원을 위한 실무 교재이다. 배관, 용접, 재료, 품질, 검사와 시험을 중심으로 현장에서 자주 쓰는 개념과 절차를 한글과 영문 용어를 함께 써서 정리했다.

## 교재 보기

**[해외플랜트_현장실무교재.pdf](해외플랜트_현장실무교재.pdf)** (8편 34개 장, 약 133쪽)

GitHub에서 파일을 열면 브라우저에서 바로 볼 수 있고, 휴대전화에서도 열람할 수 있다. 내려받아 보려면 파일 페이지의 다운로드 버튼을 쓴다.

## 이용 시 유의 사항

이 교재는 현장 실무 지식을 학습용으로 정리한 자료이다. 코드, 규격, 수치는 개념을 이해하기 위한 것이며, 실제 설계·시공·검사에는 **적용하는 코드의 원문, 프로젝트 사양서, 제작사 지침**이 우선한다. 원문 확인이 필요한 곳에는 본문에 표시해 두었다.

## PDF 다시 만들기

원고를 고친 뒤 PDF를 새로 만들려면 다음이 필요하다.

- Python 3.10 이상
- Microsoft Edge 또는 Google Chrome (PDF 인쇄에 사용)

```bash
pip install -r requirements.txt
python build_book.py
```

브라우저가 기본 경로에 없으면 환경 변수 `BROWSER`에 실행 파일 경로를 지정한다. 목차의 쪽 번호를 채우려고 PDF를 두 번 인쇄하므로 잠시 걸린다.
