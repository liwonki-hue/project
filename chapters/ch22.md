## 핵심 용어

| 용어 | 영문 | 설명 |
|---|---|---|
| 접합 | Joining | 기계적 체결, 용접, 접착을 포함하는 대분류 |
| 패스 | Pass | 아크를 발생시켜 끄기까지의 한 번의 용접 동작 |
| 비드 | Bead | 패스로 만들어진 용접금속(용접선) |
| 필러 메탈 | Filler Metal | 모재 사이를 채우는 용가재 |
| 전극 | Electrode | 용접 회로에서 전류가 드나드는 부분 |
| 루트 갭 | Root Gap | 두 모재 사이의 최단 간격 |

## {N}.1 접합과 용접

**접합(Joining)** 은 대분류이고 용접은 그 안의 소분류이다(AWS 기준).

**표 {N}-1  접합의 분류**

| 대분류 | 소분류 | 설명 |
|---|---|---|
| 기계적 체결 (Mechanical Fastening) | 볼트, 리벳 | 교량, 철골, 자동차, 항공기 등에 많이 쓴다. |
| 용접 (Welding) | 용융 용접(Fusion Welding) | 아크로 접촉면을 녹여 접합 |
| | 고상 용접(Solid State) | 폭발 용접, 확산 용접처럼 녹이지 않고 접합 |
| | 납땜, 경납땜(Soldering, Brazing) | 회로 기판의 칩 고정 등 |
| 접착 (Adhesive Bonding) | 접착제 | 접착제로 접촉면을 접합 |

용접 학회가 체결과 접착까지 연구 범위를 넓히면서 대한용접학회의 이름이 **대한용접·접합학회**로 바뀐 것도 이 때문이다.

## {N}.2 패스, 비드, 층

- **패스(Pass)**: 용접봉이나 토치로 아크를 발생시킨 뒤 꺼질 때까지의 **한 번의 동작(궤적)**. 치약을 한 번 짜는 동작에 비유할 수 있다.
- **비드(Bead)**: 한 번의 패스로 만들어진 **용접금속(용접선)**. 짜져 나온 치약 한 줄이다.
- **층(Layer)**: 하나 이상의 비드로 이루어진 용착 금속의 한 층.

패스는 작업(궤적), 비드는 그 결과인 용접금속이라는 점이 다르다.

### 다층 용접의 패스 명칭

다층 용접은 아래에서 위로 다음 순서로 쌓는다(AWS).

**표 {N}-2  용접 패스의 명칭**

| 층 | 위치·설명 |
|---|---|
| Root Pass | 루트부에 만드는 첫 번째 패스 |
| Hot Pass | Root Pass 바로 다음 패스 |
| Fill Pass (Filler Pass) | 그 위를 번호 순서대로 채우는 여러 패스 |
| Cover Pass | 대기에 노출된 최외각층. 여러 Cover Pass로 마무리된 최외각층을 **Cap**이라 한다. |

- **Intermediate Pass**: AWS에서 Hot Pass와 여러 Fill Pass를 묶어 부르는 명칭으로, Root Pass와 Cover Pass 사이의 모든 패스이다. Fill Pass는 그 구어체이다.
- **Back Bead**: 용접하는 면의 반대편으로 볼록하게 나온 부분이다.

## {N}.3 용접봉, 전극, 와이어

용접봉을 가리키는 말이 여러 가지라 혼동하기 쉽다. 핵심은 **전극 역할을 하는가**이다.

**표 {N}-3  공정별 용접봉과 전극**

| 공정 | 모재 사이를 채우는 것 | 전극 여부 |
|---|---|---|
| SMAW(피복 아크) | 피복 용접봉 | **전극**. 홀더에 물려 회로를 구성하고, 용접 중 소모되므로 소모성 전극이다. |
| GTAW(TIG) | Welding Rod(필러) | **전극이 아니다.** 전극 역할은 **텅스텐 전극**이 하며, 용접 중 매우 천천히 소모되므로 비소모성 전극이다. |
| GMAW(MIG), FCAW, SAW | 노즐에서 자동 공급되는 와이어 | **소모성 전극**. 용접 와이어라고 불러도 된다. |

- **용접봉 = 필러 메탈(Filler Metal, 용가재)** 은 모재 사이를 채우는 모든 것을 뜻하는 상위 개념이며, 전극 역할을 하는 Electrode와 하지 않는 Welding Rod를 모두 포함한다.
- Welding Rod는 막대 모양이며 전류가 흐르는 전극이 아니다. Welding Wire는 코일 형태이며 전극 역할을 하기도 하고 안 하기도 한다. TIG 필러는 **Welding Rod**가 더 정확한 표현이다.
- 용접봉 기호에서 **E**는 Electrode(전극), **R**은 Rod이다. MIG 와이어는 전극이므로 E, TIG 필러는 전극이 아니므로 R을 붙여 **ER**로 표기한다. AWS는 TIG와 MIG를 GMAW(가스 보호 아크 용접)로 통합해 같은 봉 기호를 쓴다. SAW의 F는 Flux, E는 Electrode이다.
- AWS 표준어는 Coated Electrode보다 **Covered Electrode**(피복 전극), Filler Wire보다 **Welding Wire**이다.

## {N}.4 개선 형상: 베벨, 그루브, 루트 갭, 루트 페이스

맞대기 용접을 위해 판재나 배관 끝을 그라인더로 갈아 정해진 각을 준 것이 개선(가공)이다.

**표 {N}-4  개선 형상 용어**

| 용어 | 뜻 |
|---|---|
| Bevel | 중앙선 수직을 기준으로 **한쪽 각** |
| Groove (개선, 홈) | 양쪽 전체 각(베벨의 2배). 개선과 홈은 모두 같은 뜻 |
| Root Gap (Root Opening) | 양쪽 모재의 최단 거리 간격 |
| Root Face | 루트 갭의 수직면(뾰족하지 않은 평평한 면) |
| Burn Through (용락) | 갭이 넓거나 루트 페이스가 좁아 용융금속이 아래로 떨어지는 결함 |

### 루트 갭과 루트 페이스의 역할

- 루트 갭이 **좁으면** 용접금속이 반대편으로 가지 못해 백비드를 만들기 어렵다. **너무 넓으면** 용접금속이 모재에 융착되기 전에 떨어지는 용락이 생긴다. 알맞은 갭이 **완전 용입**과 백비드를 유도해 접합 강도를 높인다.
- 루트 페이스가 없어 뾰족한 모서리면 열이 집중되어 곧바로 용락된다.
- 갭이 넓고 페이스가 좁으면 용락, 갭이 좁고 페이스가 넓으면 융합과 백비드 형성이 어렵다.

### 두께가 다른 재료의 핏업

배관과 피팅(티, 엘보)을 용접할 때 스케줄이 같아도 **피팅이 대부분 더 두껍다.** 엘보는 굽히는 과정에서 바깥쪽이 얇아지고 안쪽이 두꺼워지며, 티는 단조로 정밀 치수 가공이 어렵기 때문이다.

두께 단차가 있을 때는 WPS를 기준으로 하되, 더 자세한 개선 가공 방법은 **ASME B16.25**에 그림과 함께 나와 있다(B31.3도 B16.25를 따르도록 한다). 단차가 있을 때 얇은 쪽만 녹이고 끝내면 비파괴 검사에서 **LF, IP, Hi-Lo** 결함이 나와 갈아내고 재용접해야 하므로, 양쪽 모재를 모두 녹여야 한다.

## {N}.5 필렛 용접의 목두께

필렛 용접은 소켓 용접부, 서포트 용접부, 보강 패드 용접부 등에 쓴다. 맞대기 용접보다 이음 효율이 낮아 높은 강도가 필요한 곳에는 쓰지 않는다.

**기본 용어.** 용접부와 모재가 만나는 교차점이 **루트(Root)**, 두 모재가 만나는 모서리가 **이음매 루트(Joint Root)** 이다. 다리 길이(각장, 목길이)는 루트에서 용접 표면과 모재 표면이 만나는 점까지의 거리이다.

**표 {N}-5  필렛 용접의 목두께**

| 목두께 | 시작점 | 끝점 |
|---|---|---|
| 실제 목두께 (Actual Throat) | 루트 | 비드 표면(덧살 포함)까지의 최단 거리 |
| 유효 목두께 (Effective Throat) | 루트 | 이등변삼각형의 빗변 |
| 이론 목두께 (Theoretical Throat) | 모서리(이음매 루트) | 이등변삼각형의 빗변 |

**암기법.** 실제는 "실·루·표"(루트에서 표면), 유효는 "유·루·빗"(루트에서 빗변), 이론은 "이·모·빗"(모서리에서 빗변)으로 외운다. 현장에서는 브릿지 갭 게이지로 각장을 재거나 모서리에서 비드 표면까지의 거리를 측정한다.

    위 정의는 개념을 이해하기 위한 설명이다. 강도 계산에 쓰는 정확한 정의는 AWS 원문과 적용 코드로 확인한다.

## 요약

- 접합은 기계적 체결, 용접, 접착을 포함하며, 용접은 용융, 고상, 납땜·경납땜으로 나뉜다.
- 패스는 한 번의 용접 동작, 비드는 그 결과의 용접금속이다. 다층 용접은 Root, Hot, Fill, Cover 순이다.
- 전극 여부로 구분한다. SMAW 봉과 MIG·FCAW·SAW 와이어는 전극, TIG 필러(Welding Rod)는 전극이 아니며 텅스텐이 비소모성 전극이다.
- 루트 갭은 완전 용입, 루트 페이스는 용락 방지를 위해 필요하며, 두께가 다른 재료는 양쪽을 모두 녹여야 한다.
- 필렛 용접의 목두께는 실제(루트→표면), 유효(루트→빗변), 이론(모서리→빗변)으로 구분한다.
