## 핵심 용어

| 용어 | 영문 | 설명 |
|---|---|---|
| 표준 | Standard | 비강제적인 지침(가장 넓은 상위 개념) |
| 코드 | Code | 반드시 따라야 하는 강제 규정 |
| 사양서 | Specification | 제품·재료의 특성을 정한 기술 문서 |
| 프로젝트 사양서 | Project Specification | 발주처가 만든 고유 요구 문서 |
| 내셔널 보드 | National Board | 압력용기 검사 등록·인증 기관 |

## {N}.1 주요 표준 기관

플랜트 프로젝트의 사양서와 계약서에는 여러 기관의 코드가 등장한다. 기관마다 다루는 영역이 다르다.

**표 {N}-1  주요 표준 기관**

| 기관 | 성격 |
|---|---|
| ASME (미국기계엔지니어협회) | 보일러, 압력용기, 배관의 설계·제작·검사 코드 |
| ASTM (미국재료시험학회, 1898) | 동일한 재질로 동일한 품질의 제품을 만들기 위한 재료 표준 |
| ANSI (미국국가표준협회) | 직접 표준을 개발하지 않고 여러 협회의 표준을 관리·승인·조정 |
| API (미국석유협회, 1919) | 석유·가스, 시추 설비, 석유화학 관련 규격 제정·인증·관리 |
| AWS (미국용접학회, 1919) | 용접, 접합, 절단 표준 |

### ASME 코드의 구성

ASME 보일러 및 압력용기 코드(BPVC)는 다음과 같은 섹션으로 구성된다.

| 섹션 | 내용 |
|---|---|
| Section I | 발전용 보일러 |
| Section II | 재료 규격 (Part C는 용접봉 규격) |
| Section III | 원자력 발전 기기 |
| Section IV | 가열 보일러 |
| Section V | 비파괴 시험 |
| Section VIII | 압력용기 |
| Section IX | 용접·브레이징 자격 |
| Section X | FRP 압력용기 |
| Section XI | 원자력 발전 기기 가동 중 검사 |

!!! note "참고"
    위 표는 현장에서 자주 접하는 섹션을 중심으로 정리한 것이다. 최신 코드에는 Section XII(운송 탱크), Section XIII(과압 보호) 등이 추가되어 있다.

### 재료 규격의 접두사와 접미사

- ASME 코드가 ASTM 재료 규격을 그대로 가져올 때는 규격명 앞에 **S**를 붙인다(예: ASTM A106 → SA-106). 두 규격은 동일한 재질이다.
- ASME Section II Part C의 용접봉 규격은 AWS 규격을 그대로 가져온 것이며 **SFA**를 붙인다.
- ASTM의 분류에서 **A**는 철금속, **B**는 비철금속이다. 플랜트에서는 철금속인 A 시리즈를 가장 많이 쓴다.
- ASTM 규격 뒤의 **M**은 인치 단위와 함께 미터법으로도 표기되었다는 뜻이다.

## {N}.2 Standard, Code, Specification

세 용어는 문서의 성격에 따라 구분한다. 이들 모두 가장 넓은 개념인 Standard 아래에 놓이며, 각 문서에는 지켜야 할 요구 사항(Requirement)이 나열된다.

**표 {N}-2  Standard, Code, Specification의 비교**

| 구분 | 국문 | 성격 | 대표 예 |
|---|---|---|---|
| Standard | 표준, 규격 | 비강제적인 지침(Guideline) | ASME B16 시리즈, B18 시리즈 |
| Code | 규정(Rule) | 반드시 따라야 하는 강제 문서. 위반 시 벌금이나 법적 제재가 가능 | ASME BPVC, ASME B31 시리즈 |
| Specification | 사양서 | 제품·재료·서비스의 특성, 치수, 허용 편차, 성분, 물성을 정한 기술 지침 | ASTM, API, AWS 시리즈 대부분 |

한 기관이 세 종류를 모두 발행한다. 예를 들어 ASME는 Guideline 성격의 Standard, 강제성이 있는 Code, 기술 지침인 Specification을 모두 낸다. 문서 제목에 이 단어가 없을 때는 내용으로 판단한다.

- **호환성과 일관성**이 핵심이면 Standard이다.
- 지키지 않으면 폭발 같은 사고로 이어지는 **안전, 사고, 위험, 환경**에 관한 내용이면 Code이다.
- **품질과 성능 보장**이 핵심이면 Specification이다.

### 프로젝트 사양서(Project Specification)

**Project Specification**은 발주처(사업주)가 만든 고유 문서이다. Standard, Code, Specification에 더해 발주처의 추가 요구 사항이 명시되어 있다. 이를 지키지 않으면 계약 위반이 되므로 시공사는 반드시 이행해야 한다. 발주처는 이 문서를 리비전으로 지속 관리하여 플랜트를 안전하고 우수한 품질로 짓고 운영한다.

!!! tip "현장 팁"
    도면이나 사양서를 검토할 때는 프로젝트가 적용하는 코드와 프로젝트 사양서의 우선순위를 먼저 확인한다. 같은 규격이라도 프로젝트 사양서가 더 엄격한 조건을 요구하는 경우가 많다.

## {N}.3 ASME 코드의 탄생과 R 스탬프

### 코드가 만들어진 배경

19세기 산업혁명기의 미국에서는 증기 보일러 폭발 사고가 사회 문제였다. 표준화된 설계·제작 방법이 없었고 안전 검사 체계도 없었기 때문이다. 1880년 뉴욕에서 기계공학자들이 ASME를 설립했고, 1884년에 첫 표준인 증기 보일러 시험 규정을 냈다.

1905년 매사추세츠의 한 공장에서 일어난 보일러 폭발 사고가 결정적 계기가 되었다. 주마다 개별 법령을 만들자 ASME는 통일된 기준이 필요하다고 보고 1914년에 첫 BPVC를 만들어 1915년에 발간했다. 이후 원자력 분야는 1954년 원자력법 이후 표준화가 시작되어 1963년 Section III이 처음 발간되었다.

배관(B31)과 승강기(A17)도 같은 이유로 코드가 만들어졌다. 배관은 설계·제작·설치 기준이 제각각이라 호환성과 안전 문제가 생기자 1926년 압력배관 위원회를 구성했고, 승강기는 고층 건물이 늘면서 1921년 안전 지침이 처음 발간되었다.

### 내셔널 보드와 R 스탬프

**내셔널 보드(National Board)** 는 전국에서 동일한 규정을 강제로 사용하게 하려고 1919년에 설립된 기관이다. 압력용기의 네임플레이트에 NB 번호가 있으면 내셔널 보드에 등록된 용기이다. **U 스탬프**는 ASME Section VIII 규정으로 제작된 압력용기를, **S 스탬프**는 Section I(보일러)을 뜻한다.

공장에서 제작되어 현장에 입고된 압력용기를 설치 과정에서 절단·용접으로 수정해야 할 때(예: 노즐이 배관이나 기초와 간섭해 방향을 바꿔야 할 때)는 **R 스탬프** 절차를 따라야 한다.

1. 내셔널 보드 검사 코드(NBIC)의 Part 3 Repairs and Alterations를 기준으로 한다.
2. 수정 작업 전에 내셔널 보드의 공인검사기관(AIA)과 계약하고 작업 범위와 방법을 협의한다.
3. 공인검사자(AI)가 현장에 도착하면 그 입회하에 작업한다.
4. 노즐 수정 후에는 압력용기 전체를 수압시험 하는 대신, NBIC에 명시된 대로 비파괴 검사로 대신할 수 있다.

ASME 스탬프 자격은 유효 기간이 3년이어서 3년마다 갱신한다. 업체가 비용을 들여 유지하는 이유는 해외 발주처가 이를 요구하고, 품질관리 체계가 향상되며, 고객의 신뢰를 얻고, 설치와 수정 작업을 직접 수행해 공기와 원가를 줄일 수 있기 때문이다.

## {N}.4 재질 규격의 비교

같은 자재라도 나라별 코드에 따라 명칭이 다르다. 유럽 EN 규격의 자재가 ASME/ASTM의 어느 재질과 같은지 알아야 할 때는, 여러 나라의 재질 규격을 동일 자재끼리 묶어 놓은 비교표를 활용한다. ASTM에서 발행하는 공식 재질 비교표가 있다.

!!! warning "주의"
    규격 간 등가 표시가 화학 성분과 기계적 성질의 완전한 일치를 뜻하지는 않는다. 대체 사용 전에는 성적서와 프로젝트 사양서로 확인한다(제9장 참고).

## 요약

- ASME는 설계·제작·검사, ASTM은 재료, ANSI는 표준 승인·조정, API는 석유·가스, AWS는 용접 표준을 다룬다.
- Standard는 비강제 지침, Code는 강제 규정, Specification은 제품·재료의 기술 사양이다. 프로젝트 사양서는 여기에 발주처의 추가 요구를 더한 계약상 의무 문서이다.
- ASME 재료 규격의 S는 ASTM을, SFA는 AWS 규격을 그대로 채택했다는 표시이다.
- ASME 코드는 보일러 폭발 사고에서 출발했으며, 압력용기의 현장 수정은 내셔널 보드 R 스탬프 절차를 따른다.
