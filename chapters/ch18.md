## {N}.1 플랜지 클래스와 형식

### 플랜지 클래스

도면과 BOM의 `150#`은 플랜지의 사용 압력과 온도를 고려해 정한 숫자이다. "클래스 150" 또는 "150 파운드"라고 읽는다(ASME B16.5, B16.47). 클래스는 **압력과 온도에 따른 등급을 나타내는 무차원수**이며 무게가 아니다.

클래스가 높을수록 같은 크기에서 플랜지가 더 커지고 두꺼워지며 볼트가 굵어지고 대체로 많아진다. 배관과 연결되는 안쪽 직경은 같다.

### 플랜지 형식

측면 형상에 따라 웰드넥(Weld Neck), 슬립온(Slip-On), 소켓웰드(Socket Weld), 랩조인트(Lap Joint), 스레디드(Threaded), 블라인드(Blind)가 있다.

**표 {N}-1  웰드넥과 슬립온의 비교**

| 구분 | 웰드넥 | 슬립온 |
|---|---|---|
| 배관 연결 | **맞대기(버트) 용접** | **필렛 용접** |
| 이음 효율 | 좋다. | 상대적으로 낮다. |
| 사용 조건 | 고온·고압 | 상대적으로 낮은 압력·온도 |
| 제작·납기 | 제작이 오래 걸려 납기가 길다. | 간단해 빠르고 저렴하다. |

### 접촉면

현장에서는 접촉면이 평평한 **Flat Face(FF)** 와, 접촉면이 살짝 올라와 기밀 유지에 효과적인 **Raised Face(RF)** 를 가장 많이 쓴다.

## {N}.2 대구경 플랜지: ASME B16.47 Series A와 B

ASME 코드에서 **24인치 이하** 플랜지는 **ASME B16.5**, **26인치 이상** 플랜지는 **ASME B16.47**을 따른다. B16.47에는 **Series A**와 **Series B**가 있으며, 같은 크기라도 볼트홀의 개수와 위치가 서로 달라 **호환되지 않는다.**

**유래.** 1980년대 미국 시장에는 제작사들이 만든 규격(MSS SP-44)과 API 규격의 두 가지 플랜지가 유통되었다. 사이즈는 같지만 볼트홀 개수와 위치가 달라 혼용이 불가능했다. ASME는 MSS 규격을 Series A, API 규격을 Series B로 나누었다.

**표 {N}-2  플랜지 규격의 적용**

| 크기 | 규격 | 비고 |
|---|---|---|
| 24인치 이하 | ASME B16.5 | |
| 26인치 이상, Series A | ASME B16.47 A | MSS SP-44 계열 |
| 26인치 이상, Series B | ASME B16.47 B | API 계열 |

!!! warning "주의"
    볼트홀이 맞지 않으면 체결할 수 없어 공기 지연과 발주처의 신뢰 하락이 생긴다. 다음 경우에는 발주 전에 시리즈를 도면에서 반드시 확인한다.
    
    1. 기계장치 노즐과 GRP 플랜지를 체결할 때
    2. 오래된 기존 공장 플랜지와 신규 배관을 연결(타이인)할 때
    3. 유럽 코드 플랜지와 ASME 코드 플랜지를 체결할 때
    4. 서로 다른 벤더가 만든 플랜지끼리 체결할 때

## {N}.3 라인 블랭크: 스펙타클 블라인드, 블랭크, 스페이서

플랜지 사이에 넣어 유체 흐름을 막는 부속은 ASME B16.48(Line Blank)에서 세 가지로 부른다.

**표 {N}-3  라인 블랭크의 종류**

| 정식 명칭 | 별칭 | 기능 |
|---|---|---|
| Figure-8 Blank | Spectacle Blank(Blind) | 막는 Blank와 여는 Spacer가 한 세트 |
| Paddle Blank | Blind, Spade | 흐름을 막는다. |
| Paddle Spacer | Spacer, Ring Spacer | 열린 상태를 유지한다(공간을 채운다). |

Paddle은 카누의 짧은 노를 뜻하며 모양이 닮았다. Spectacle은 안경을 뜻하며 옛 동그란 안경과 닮았다.

**Spacer가 필요한 이유.** 라인은 Blank를 넣을 공간을 감안해 구성되어 있으므로, 평소 유체를 흘리려면 그 자리를 채우는 Spacer가 없으면 양쪽 플랜지가 서로 체결되지 않는다.

**Blank와 Spacer의 어원.** Empty는 아무것도 없는 3차원 체적을, **Blank**는 아무것도 없는 2차원 평면(막힌 평면)을, **Spacer**는 뚫려 비어 있는 공간을 뜻한다.

## {N}.4 볼트홀 배치: 스트래들 규칙

플랜지의 볼트홀 위치를 보면 **중심선을 기준으로 좌우에 같은 개수**의 볼트가 있다. 서로 다른 곳에서 제작된 스풀과 기계 노즐의 플랜지도 현장에서 볼트홀이 일치하는 이유는, ASME 플랜지 코드, API, PIP가 **중심선 위에 볼트홀이 없도록(Straddle) 좌우 같은 간격·같은 개수로 설치**하라고 정하기 때문이다. 볼트 체결의 대표 규정인 ASME PCC-1도 같은 규칙을 전제로 한다. 볼트홀 수는 4, 8, 12, 16개처럼 **4의 배수**이다(ASME B16.5).

**왜 Straddle인가.** 코드에 명확한 이유는 없지만 다음과 같은 이유가 거론된다.

1. 오랜 관습이 규칙이 되었다.
2. 같은 개수의 볼트가 양쪽에서 균일하게 잡아 스트레스와 누설에 더 안정적이다.
3. 설치와, 이미 설치된 플랜지의 수평 측정이 쉽다.
4. 중심선에 볼트를 두면 빗물이나 누설 유체로 최하단 볼트에 부식이 집중될 수 있다.
5. 최상단 볼트를 안쪽에서 체결하거나 풀 때 밸브 바디와 간섭해 작업이 어려울 수 있다.

### 45° 엘보 스풀의 주의점

기계 노즐과 연결되는 스풀은 현장의 간섭 때문에 **45° 기울어져 설치**되는 경우가 많다. 이런 스풀을 샵에서 일반적인 Straddle 방식으로 제작하면 현장에서 볼트홀이 맞지 않아, 절단과 재용접으로 일정이 지연된다. 볼트홀이 많고 두꺼운(Heavy Wall) 대구경일수록 심각하다.

!!! tip "현장 팁"
    45° 엘보가 붙는 스풀은 현장의 설치 방향을 미리 확인하고, **회전할 각도를 감안해** 볼트홀이 중심선에 오도록 제작한다. 실수를 줄이려면 플랜지와 배관 조인트는 태그 용접만 하고 **본 용접은 현장에서** 하도록 권장한다.

## {N}.5 가스켓

가스켓은 볼트로 체결되는 연결부에서 내부 유체가 새지 않도록 **기밀성**을 유지한다. **ASME B16.20은 메탈 가스켓**, **B16.21은 논메탈 가스켓**을 다룬다.

### B16.20의 대표 가스켓

| 종류 | 특징 |
|---|---|
| 링 조인트(Ring Joint) | 가스켓 링이 플랜지 홈에 들어가는 타입. 기밀성이 우수해 고온·고압에 쓴다. 플랜지보다 강도가 높으면 체결 시 플랜지가 손상될 수 있어, 플랜지와 **같거나 낮은 강도**를 권장한다. |
| 스파이럴 와운드(Spiral Wound) | 현장에서 가장 많이 쓴다. 압력·온도 범위가 다양하고 기밀성이 우수하다. |
| 자켓드(Jacketed) | 많이 쓰이지는 않으며 열교환기 내부나 컨트롤 밸브 커버 등에 쓴다. |

### 스파이럴 와운드 가스켓의 구성

| 구성 | 역할 |
|---|---|
| 아우터링(가이드링) | 볼트와 맞닿아 중심을 잡아 설치가 쉽고, 압축 시 필러가 팽창해 망가지지 않게 모양을 잡는다. 산화 방지 페인트가 칠해진 탄소강이다. |
| 필러 | 와이어와 그라파이트(흑연)가 겹겹이 나선형으로 감긴 부분. 흑연은 신축성과 산화 방지에 좋고 압축 후 밀도가 높아져 기밀성이 좋다. |
| 이너링 | 압축에 의한 필러 변형을 막는다. 유체와 직접 닿으므로 내식성이 좋은 스테인리스를 쓰며 **재질은 필러의 와이어와 같아야** 한다(예: 둘 다 316). |

### 현장에서 자주 나오는 세 가지 이슈

1. **왜 1회만 쓰는가.** 한 번 압축된 가스켓은 신축성이 떨어져 재사용하면 새것보다 플랜지와의 기밀성이 떨어진다. 플랜지를 풀었다 다시 조일 때는 새것을 쓰는 것이 원칙이다.
2. **아우터링이 휘어진 경우.** 발주처가 불량이라며 전량 교체를 요구하기도 하지만, 가스켓에서 가장 중요한 부분은 기밀을 유지하는 **필러**이므로 아우터링이 휘어져도 내부 팽창 방지 기능은 충분하다.
3. **탄소강 아우터링과 스테인리스 필러의 이종 재질 부식.** 스테인리스는 탄소와 만나면 입계 부식이 활발해지는 것을 우려하지만, 아우터링과 필러의 접촉부는 압력과 온도를 견디며 유체와 직접 닿는 부위가 아니고, 아우터링은 페인트 코팅되어 있고 와인딩은 여러 겹이며, 가스켓은 한 번 쓰고 교체하는 자재이므로 문제가 되지 않는다.

## 요약

- 플랜지 클래스는 압력·온도 등급을 나타내는 무차원수이며, 클래스가 높을수록 플랜지가 크고 두껍고 볼트가 굵다. 웰드넥은 맞대기 용접이라 슬립온보다 고온·고압에 쓴다.
- 26인치 이상은 B16.47이며 Series A와 B는 볼트홀이 달라 호환되지 않으므로 발주 전 확인한다.
- Figure-8 Blank(스펙타클), Paddle Blank(블라인드), Paddle Spacer는 B16.48의 라인 블랭크이다.
- 볼트홀은 중심선 위에 두지 않는 Straddle이 규칙이며, 45° 엘보 스풀은 회전 각도를 감안해 제작한다.
- 스파이럴 와운드 가스켓은 아우터링, 필러, 이너링으로 구성되고 1회 사용이 원칙이다.
